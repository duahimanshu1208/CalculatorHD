CalculatorHD

A simple Android calculator app built with Kotlin and Jetpack Compose. It supports addition, subtraction, multiplication, division, and decimal numbers, with a clear button and an "Error" message for dividing by zero. Built while learning the basics of Kotlin and Compose.

Features:
Addition, subtraction, multiplication, and division
Decimal numbers
Chained operations, for example 2 + 3 + 4
Clear (C) button to reset the calculator
Shows "Error" when dividing by zero
Whole-number results are shown without a trailing .0 (7, not 7.0)

Built with:
Kotlin
Jetpack Compose
Material 3
Android Studio
